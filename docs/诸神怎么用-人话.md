# 诸神以后怎么干活 · 人话版

> 给立境者闫滨：不堆术语，只讲「谁在哪、你怎么用」。

---

## 一句话

**诸神不是 9 个手机 App**，而是：**同一个 Cursor 里，不同「岗位说明书」+ 你换哪个窗口 / 打开哪个文件夹，就轮到哪个神说话。**

**记忆**不在聊天里，在 **GitHub 灵台仓库**（柏鉴 = 这个仓库本身）。

---

## 用公司打比方

| 封神里 | 现实里 |
|--------|--------|
| **柏鉴** | 公司的档案室（`Jiangziyamemory` 文件夹 + 网页灵台） |
| **姜子牙** | 总经理办公室（Cursor 里日常这条对话，统筹） |

| **魔礼青** | 质检科（打开 `tasks/` 或专用对话，只查「做完了吗、有证据吗」） |
| **首星（树莓派）** | 门口一盏灯，表示「人在」，不是打字聊天 |

以前腾讯云上的姜子牙 = **换了一家公司外包的客服**；你现在说不满意，所以**不再用那家**，改在 **Cursor（你正在用的这个）** 里重新任命诸神。

---

## 「一神 = 一个 Cursor 对话 + 一份 md」是什么意思？

不是装 9 个软件。

而是：

1. **每个神有一份岗位说明** → `docs/agents/魔礼青.md` 这种文件（姜子牙已经写好或正在写）。  
2. **你要找谁办事，就怎么用 Cursor：**  
   - 找姜子牙统筹 → 平时这条对话就行。  
   - 找魔礼青验收 → **打开 `tasks/待办榜.md`** 再说话（仓库里已配好规则，AI 会按魔礼青行事）；或新建对话 @ 魔礼青.md。  
   - 找闻仲执行 → 另开对话 @ 闻仲.md，让他跑终端、改文件。

**换对话 = 换神值班**；**写进仓库 = 柏鉴记史**。

## 姜子牙（我）能替你「搭建」什么？不能做什么？

| 我能做（已经或可以写在仓库里） | 你不能指望我自动做 |
|-------------------------------|-------------------|
| 写魔礼青的岗位说明 `docs/agents/魔礼青.md` | 在你电脑上**自动点出**一个叫魔礼青的新聊天窗口 |
| 写待办榜、验收单 | 代替你登录腾讯云 |
| 配 **Cursor 规则** `.cursor/rules/魔礼青-验收.mdc`：你打开 `tasks/` 文件时，AI 按魔礼青说话 | 变出第二个完全独立的「机器人账号」 |
| 在本对话里**临时扮演**魔礼青给你演示验收 | 长期应专用对话或 tasks 规则，避免和姜子牙混 |

**所以：**「搭建魔礼青」= 档案 + 流程 + Cursor 规则都已在灵台；**你只需打开 `tasks/待办榜.md` 问一句「验收 T002」**，不必再去腾讯云。

若你坚持要**单独一个聊天标签**写着魔礼青：在 Cursor 点一次 **New Chat**，粘贴 `docs/魔礼青上岗.md` 里那三行字 —— 这是点鼠标的事，任何 AI 都替不了你点。

## 手机 / 网页以后呢？

- **现在**：用手机看 **灵台网页** 读记忆；要办事回家用 **Cursor**。  
- **以后世界搭好**：做一个**自己的网页**，背后接境外 API — 仍不是国内 Agent 黑箱。  
- **App**：你说不着急，那就最后再说。

## 你现在试魔礼青（30 秒）

1. 在 Cursor 左侧打开 **`tasks/待办榜.md`**  
2. 在对话里输入：**「请按魔礼青验收 T002」**（若已 push，附 GitHub commits 链接）  
3. 看回复是否带 **`【魔礼青验收】`** 和「通过/不通过」

若规则未生效，新建对话，首条 @ `docs/agents/魔礼青.md` @ `tasks/待办榜.md` 即可。
