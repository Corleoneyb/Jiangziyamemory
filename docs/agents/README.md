# 诸神 Agent · 真身搭建说明

## ADP 是什么意思？

在你们 **2026-05-15** 的家底里写的是：**「在 ADP 平台创建独立的闻仲和姜子牙智能体」**。

**ADP = Agent Development Platform（智能体开发平台）** 的缩写，泛指「在网页/App 里创建一个带独立人设、独立对话入口的 AI 智能体」，不是封神世界专有名。

灵台卷宗**没有记下**你当时具体用的是哪一个产品（常见例如 **扣子 Coze**、豆包智能体、腾讯元器、讯飞星辰等）。  
**请你回忆**：当年做姜子牙、闻仲时打开的是哪个网站/App？那就是你的 ADP；**魔礼青应在同一平台再建一个智能体**，人设文件用本目录下各神的 `*.md`。

| 方式 | 是什么 | 适合谁 |
|------|--------|--------|
| **ADP（云端智能体）** | 独立聊天入口、独立系统提示词 | 姜子牙、闻仲、**魔礼青**、张良 — 手机也能点开 |
| **Cursor Agent** | 本机开发对话，能读写在仓库 | 姜子牙写灵台、闻仲动手、魔礼青验收时可 `@tasks/` |
| **柏鉴** | 不是聊天 Agent | 本仓库 + `memories/` |
| **首星** | 树莓派程序 | 不是大模型 |

**真要「能干活、真实存在」**：至少要在 **ADP 或 Cursor 里有一个单独会话/智能体**，只干魔礼青的事，而不是只在 `docs` 里写制度。
