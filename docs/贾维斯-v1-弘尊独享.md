> **弘尊裁定 B** · 2026-05-23

---

## 一、愿景（一句话）

弘尊只管**碳基世界必须人办的事**；其余读卷、改文件、跑终端、督办、盯帖、派活闭环——**全在本条对话由姜子牙（贾维斯）当轮办完**，不叫弘尊去别的 Agent 窗、不默认手贴派单。

---

## 二、v1 与 v2 边界

| 维度 | **v1（现在）** | **v2（以后）** |
|------|----------------|----------------|
| 入口 | 本条姜子牙对话 = 唯一对弘尊界面 | 更强隔离：独享部署、专用机/容器 |
| 诸神 | 仓库内神位资料**保留**；对弘尊**冻结**「再开闻仲/金灵专窗、手贴派单」 | 可恢复多窗，但须弘尊另令解冻 |
| 执行 | 姜子牙本窗：终端、改 `tasks/`/`deliverables/`、写工单、内部子任务 | 自动化派单、本地模型、24h 无人值守深化 |
| 部署 | **本地或云均可**（Cursor + 本机 Git + 可选殿址机 cron） | **路线图承诺：未来一定本地部署**（卷宗与脚本主控在弘尊侧） |
| 弘尊 | 裁决、付款、登录外站、露脸回评、开户等 | 不变：碳基清单 |

**不删诸神文件**：`docs/agents/`、`deliverables/`、`tasks/诸神并行工单.md` 等照旧；只是**弘尊 UX 上不再默认「去某神窗」**。

## 三、弘尊清单 vs 贾维斯清单

### 弘尊只做（碳基）

- **裁决**：红绿灯 准 / 续议 / 否；P0 拍板；口头「8、9 准」「帖准，发」等  
- **付款**：采购、订阅、硬件下单  
- **登录外站**：即刻 / V2EX 等账号登录、发帖点击发送、私信露脸  
- **露脸回评**：需要真人语气、身份的回复  
- **开立账户**：外站注册、收款码展示、实名类操作  
- **举证**：发帖后站名、标题、日期等（G1）；无法自动化的截图/扫码  

### 贾维斯（本条姜子牙）全办

- 读改仓库、`memories/`、开卷封卷  
- **跑脚本与终端**（闻仲类活由本窗执行，不甩「去闻仲窗」）  
- 听音、听榜、扫 `deliverables/`、维护督办简表  
- **盯帖自动化**：派工、写 `scripts/`、记缺口、催证据落盘  
- 派活闭环：写工单、改并行表、当轮催缺件  
- 内部可用子任务分解，**不要求弘尊开新 Agent**

## 五、诸神冻结说明（对弘尊界面）
