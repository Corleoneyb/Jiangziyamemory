# 对着谁说 · 一张图就够

## 只有两种窗口

| 窗口 | 你是谁 | 你怎么开 | 你说什么 |
|------|--------|----------|----------|
| **本对话** | 跟 **姜子牙** 说话 | 就是现在这条 Cursor 聊天 | 听音 / 听榜 / 封卷 |
| **新 Agent** | 跟 **某一尊神** 说话 | Cursor 点 **New Agent** → 首条粘贴该神开卷语 | 直接派活，例如「写盈利假设表」 |

**不要把赵公明、范蠡的开卷语贴给姜子牙。**  
姜子牙是总线；赵公明、范蠡是专线，各开一个 New Agent。

## 今天你要开两神时

1. **New Agent** → 粘贴 **赵公明** 那段 → 回车 → 你只跟**这个窗口**里的赵公明说话  
2. 再 **New Agent** → 粘贴 **范蠡** 那段 → 回车 → 你只跟**这个窗口**里的范蠡说话  
3. 汇总、派闻仲、批红绿灯 → 回到 **本对话** 找姜子牙

## 语音时更简单

| 你说（常听开着） | 谁处理 |
|------------------|--------|
| 日常决策、派活、批阅 | 说完 → 本对话：**听音** |
| 专让赵公明写表 | 说完 → 去 **赵公明那个 Agent** 窗口打字或再贴一句 |
| 专让范蠡写 MVU | 去 **范蠡那个 Agent** 窗口 |

**加速原则**：能跟姜子牙说一句的，不自己开第三、第四个窗口。
