---

## 验收啥

**Pi 重启后，不用 SSH**，上电 **2～3 分钟内** 灯自己跑一遍灯语（暗蓝呼吸 → 暖橙），与手动 `python3 ~/rgb_breath.py` 观感一致即可。  
服务 **Type=oneshot**：开机跑一次，**不是** 24h 常驻呼吸。

---

## 证据（缺一条 = 待补证）

| # | 证据 | 说明 |
|---|------|------|
| 1 | `systemctl status rgb_breath.service` 截图或复制文本 | `active (exited)` 且成功类即可 |
| 2 | `systemctl is-enabled rgb_breath.service` 输出 | 须为 `enabled` |
| 3 | **断电/重启** 后 **2～3 分钟** 内灯自跑 | 照片或短视频 |
| 4 | 若失败 | `journalctl -u rgb_breath.service -n 40` 文本 |

## 结论栏（魔礼青填）

| 结论 | 条件 |
|------|------|
| **通过** | 1+2+3 齐，灯语肉眼对 |
| **不通过** | 重启不亮或报错 |
| **待补证** | 缺截图/缺 journal |
