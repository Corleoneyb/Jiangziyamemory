手把手 · 殿址机诸神并行

给 WPS / Word：本文件为 HTML（不是苹果专有格式）。用 WPS「打开」选本文件，或拖到浏览器里看。与 docs/手把手-殿址机.md 内容一致。

对应：立境者殿址机（Windows 台式机）。一次一步；做完回姜子牙「第 N 步好了」。

这台机器干什么

  • 开多个 Cursor Agent（比干、吴道子、闻仲…）并行写 deliverables/
  • 跑柏鉴程序 scripts/bailian_digest.py（可选定时）
  • 不要求 24h 空转：干完一批可关机，见排班文档

第 1 步 · 装 Cursor

  1. 浏览器打开 https://cursor.com
  2. 下载 Windows 版，安装，登录（与 Mac 同一账号即可）
  3. 打开 Cursor，能进主界面 → 回「Cursor 好了」

第 2 步 · 装 Git

  1. 打开 https://git-scm.com/download/win
  2. 一路 Next 安装（默认即可）
  3. 开始菜单搜 Git Bash，打开，输入：
    git --version
    出现 git version 2.x → 回「Git 好了」

第 3 步 · 克隆灵台

在 Git Bash 里（路径按你习惯改）：

cd ~
git clone https://github.com/Corleoneyb/Jiangziyamemory.git
cd Jiangziyamemory

克隆成功 → 回「仓库克隆好了」

第 4 步 · 装 Python（柏鉴用）

  1. 打开 Python Windows 下载页
  2. 装 Python 3.12+，勾选 Add python.exe to PATH
  3. Git Bash 里：
    python --version
python scripts/bailian_digest.py
    看到【柏鉴摘要】已写入 → 回「柏鉴跑通了」

第 5 步 · 自动 push

bash scripts/install-auto-push-hook.sh

第 6 步 · 开神 Agent

见仓库 docs/agents/开卷指令.md 与 tasks/诸神并行工单.md。
