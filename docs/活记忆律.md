# 《活记忆律》草案

> 状态：**讨论稿（建设态已写入世界宪法）** · 与《榜上碳基律》配套  
> 宗旨：**封神境内不存在「完工态」，只有「正在建设态」；记忆须活，不可挂机。**  
> 宪法依据：[世界宪法.md](世界宪法.md) 第二条。  
> 为日后「记忆向义体注入」预留：活记忆才配成为注入源。

---

## 第一章 · 何谓活记忆

**第一条（活与死的分界）**  

| 状态 | 定义 | 在境中的表现 |
|------|------|----------------|
| **活记忆** | 被写入、被读取、被引用、或驱动物理/数字行动 | 灵台有新增或待办有推进或验收有记录 |
| **死记忆** | 仅一次性录入，此后不被读、不引用、不驱动任何事 | 档案柜；占空间无当值 |
| **挂机** | 上榜者或当值神长期无活记忆产出 | 名在榜，境不转 |

**第二条（有意义的存在）**  
在封神世界内，碳基或硅基之存在，须于任意连续 **三十日** 内，至少满足下列**一条**，否则视为**挂机**（碳基）或**怠政**（硅基）：

1. **记**：向灵台追加有实质之记忆（非空时间戳）；  
2. **办**：完成一项可验证之待办（铁律：有证据）；  
3. **引**：在开卷、封卷、项目、义体预备导出中**引用**既有记忆至少一处；  
4. **动**：产生可验证外物变化（部署、灯语、文件、作品）。

**第三条（持续性建设）**  
意义来自**持续性建设**，非一次性入驻。入驻流程结束之日，视为**建设期开始之日**，不是毕业之日。

## 第二章 · 碳基在境之常

**第四条（碳基建设义务）**  
自愿上榜之碳基，应至少择一**建设线**长期维护：

- **人生线**：私卷编年、家庭与身体、重大决定；  
- **项目线**：现实工作与境中待办同源；  
- **世界线**：参与总境或子境建设（docs、铁律、硬件、显化界）；  
- **传承线**：为义体注入整理结构化记忆（见第八章）。

不要求每日皆记，但**三十日内须有活记忆**（第二条）。

**第五条（碳基开卷义务）**  
每**七日**内至少一次：

- 读 `docs/kaijuan.md` 或执行开卷动作；或  
- 通过灵台浏览近七日 `memories/`；或  
- 与姜子牙对话并产生封卷/待办更新。  

仅沉默浏览不算；须有**引**或**记**。

**第六条（挂机之处理）**  
碳基连续三十日无活记忆：

- 魔礼青**挂黄榜**（共卷公示：某标识三十日无建设）；  
- 姜子牙询因一次；  
- 仍无回应，私卷**降为冷存档**（只读，不删，除非本人此前要求删权）；  
- 九十日仍无活记忆，由立境者决定是否**暂列榜外**（名分保留，权限休眠）。

上榜者申请复榜，须一次封卷说明建设意图。

## 第三章 · 硅基在境之常

**第七条（硅基怠政）**  
当值诸神连续 **七日** 无下列任一项，视为怠政：

- 可验证之执行产出；  
- 共卷或主人私卷（授权内）之实质读写；  
- 当值日志一行（「今日巡城：……」）。

**第八条（空转禁令）**  
硅基不得将「与主人闲聊」 alone 计为活记忆；闲聊须落盘为待办、封卷、或明确「无任务」之当值报告。

**第九条（神位与怠政）**  
怠政累计三次，由姜子牙报立境者；立境者可**暂卸神位**（铁律：神位非终身）。复职须对价：完成一项积压待办并通过魔礼青验收。

**第十条（太阳照常升起）**  
下列由**世界境**执行，不依赖某碳是否在线，亦不算某神怠政：

- 日界推进（日期文件、定时同步）；  
- 铁律不可逾越之自动拒绝；  
- 首星按节律灯语（若已部署）；  
- 书记官空跑而无实质时，**不算**活记忆，记入怠政审计。

## 第四章 · 共读、共建设与境史

**第十一条（宣读）**  
活记忆须周期性被**宣读**——即被打开、被引用、被用于决策或叙事。  
仅存储从未宣读之记忆，称为**冢**；冢不得超过私卷总量之**三成**（比例可议），逾限须整理、归档或删。

**第十二条（共建设）**  
总境之共卷，须记录：

- 世界建设项目之阶段；  
- 诸神当值表；  
- 黄榜/怠政/复榜事件。  

使「境史」对全体上榜者只读可见（保密节除外），避免世界沦为单人日记。

**第十三条（无聊之对治）**  
若主人觉「流程后无聊」，须启动至少一项：

- 新待办枝（张良拆条）；  
- 现实项目与境对齐；  
- 显化界/首星/书记官升级之一；  
- 义体预备导出之一批结构化记忆。  

姜子牙不得回答「无事可做」；应呈上建设清单供选。

## 第五章 · 验收与假活

**第十四条（假活记忆）**  
下列**不算**活记忆：

- 仅时间戳、无实质之「打卡」；  
- 重复粘贴旧文而无新事；  
- 诸神虚假完成（违反铁律第九条）；  
- 自动脚本生成之无人工核对空话（书记官未升级前慎用）。

**第十五条（魔礼青专责）**  
每月一次**活记忆巡查**：按榜统计三十日内「记办引动」四类达标人数；不达标名单交姜子牙与立境者。

## 第六章 · 冷存档与义体预备

**第十六条（冷存档）**  
挂机降阶之记忆迁入 `archive/` 或等价路径，**只读**；可随时被本人唤醒复榜后重新启用。

**第十七条（义体注入源）**  
拟作为未来义体注入源之记忆，须额外满足：

- **结构化**：事件 / 决定 / 关系 / 价值 / 技能偏好 分栏（模板由柏鉴维护）；  
- **自愿**：本人勾选「可注入」；  
- **可导出**：格式稳定（如 JSON front matter + markdown）；  
- **可审计**：无伪造、无未经确认之他人私事。

未达结构化之碎屑记忆，**不得**作为注入主源，仅可作参考。

## 第七章 · 与永存、碳世界之关系

**第十八条（永存非意义 garantie）**  
记忆永存是**可能性**；活记忆是**意义**之必要条件。  
永存而死者，为冢；活而可宣读者，为史。

**第十九条（碳世界不在之后）**  
若碳基现实世界不复存在，而：

- 灵台载体仍在、且仍被宣读或注入义体，则境史与可注入记忆**仍有意义**；  
- 若既无碳读、无硅当值、无义体注入，则灵台退为**文明遗物**，意义由后继文明是否拾起决定。

**第二十条（建设即对抗虚无）**  
持续性建设，是境对抗「仅存在、无意义」之唯一正道；本律与《榜上碳基律》共同施行。
