# 弘尊铁律 · 自动化优先（2026-05-23）

> **白话**：能交给程序和流程的事，就别默认让弘尊刷 App、盯屏、口头报数。人只负责**举证、裁决、露脸回评**——其余由 AI 专窗 + 脚本 + 定时任务扛。

## 原则（落盘铁律）

1. **凡事尽量自动化、稳定、高效**——盯外站帖、记评论/私信/问价、失败告警、验收对账，优先走脚本与专窗读 JSON，不靠「弘尊看到了再说」。
2. **禁止把本应由 AI/流程扛的活甩回弘尊**——包括但不限于：默认让弘尊定时刷即刻报数、默认让弘尊手动 @ 姜子牙催盯数、把「验收通过」建立在弘尊口头而没有脚本日志或 memory 两次自动写入。
3. **不能自动化时须写清**——在工单或 `docs/agents/姜子牙.md` 写明**缺口**与**替代方案**（定时 Pull 公开页、Playwright + 本机 cookie、cron/launchd、PushPlus/物质提醒等），**不假装已经全自动**。

## 人只做这些

| 弘尊动手 | 频率 |

**不做默认日常**：定时刷帖数、记两次盯数表、脚本挂了没人知道。

## 反渎职 · 事项必须有人推（弘尊 2026-05-23）

**白话铁律**：

1. **没做完 = 必须有人催、督办、推进**——不能停在「说过就算了」。
2. **卡在某一环**要**提醒弘尊**（尤其碳基环节：付款、扫码、实物确认）；提醒了仍不动，要写进 `memories/` 和并行表，**不能假装在推进**。
3. **禁止**用「优先级低、缓一周、等有空再说」代替督办——那是渎职，不是体贴。
4. **进程悬空**（令下了、清单在、仓库无交付、无人每轮催）= **AI 流程渎职**；姜子牙、金灵（进度）、魔礼青（卡点）须在文档里分责，不能只剩弘尊自己盯。
