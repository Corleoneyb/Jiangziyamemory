## 第 1 步 · 只认针脚（先不通电）

1. 把 **KY-016** 拿在手里，找到板上印字，常见四针：

   | 丝印 | 含义 |
   |------|------|
   | R / G / B | 红、绿、蓝 |
   | GND 或 `-` | 地 |
   | 有的板子中间两针是 VCC/GND，以你板子印字为准 |

2. 拍一张**清晰照片**（针脚与印字），或写下从左到右四针分别印什么。

3. 回姜子牙一句：**「四针从左到右是：___」** 或发照片说明。

**本步不要**插树莓派、不要上电。
