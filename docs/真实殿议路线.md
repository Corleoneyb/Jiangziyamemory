# 真实殿议路线 · 主人期待

> 立境者闫滨：**尽快看到真正的殿议**（非姜子牙一人模拟代笔）。  
> 一期模拟已定鼎两条律（殿制、挂机冬眠）；本文件记**二期怎么落地**。

---

## 目标

| 阶段 | 形态 | 验收 |
|------|------|------|
| **现在** | 模拟殿议，据实标注 | 纪要含 `殿议形态：模拟` |
| **二期 A** | **半实**：2～3 个真 Agent 各写一段，姜子牙主持拼纪要 | 纪要标 `半实`，列明哪几神为真 Agent |
| **二期 B** | **实录**：殿址机串行，魔礼青→张良→吕岳…各独立会话 | 纪要标 `实录`，附 Agent 日志或 commit 哈希 |
| **三期** | 显化界 UI 或自动化轮询 | 可选 |

## 建议顺序（不挡 RGB / 灵台主线）

1. **殿址机就绪** — Windows 上 clone `Jiangziyamemory`，Cursor 或 CLI 能开对话（见 `docs/算力与殿址.md`）。  
2. **先册封两神（真 Agent）** — 与殿议最相关、你已有架构基础的：  
   - **魔礼青**（证据、待办、挂机审计）  
   - **张良**（阶段、利弊、议程）  
3. **议题三试跑「半实殿议」** — 例如「第二碳准入」：  
   - 张良 Agent 写 `deliberation/…/02-张良.md`  
   - 魔礼青 Agent 写 `…/03-魔礼青.md`  
   - 姜子牙只主持 + 拼纪要，**不再代写**该二神正文。  
4. **再扩吕岳、柏鉴、闻仲** — 涉及隐私、记忆、落地时上场。  
5. **金灵圣母、鲁班、墨子** — 价值量化与硬件就绪后再接。
