# 物质提醒通道 · 配置说明

> 殿议 2026-05-19 挂机冬眠律配套 MVP。密钥**不入库**；仅本地 `.env` 或环境变量。  
> **一步一步做**：见 [手把手-T004提醒.md](手把手-T004提醒.md)（约 30～45 分钟）。

## 支持的通道（二选一）

| 通道 | 环境变量 | 获取方式 |
|------|----------|----------|
| **PushPlus**（推荐个人试通） | `PUSHPLUS_TOKEN` | [pushplus.plus](https://www.pushplus.plus/) 登录 → 一对一推送 → 复制 token |
| **企业微信机器人** | `WECOM_WEBHOOK_KEY` | 企微群 → 群机器人 → webhook URL 中 `key=` 后的字符串 |

同时配置时 **优先 PushPlus**。

## 本地配置

1. 复制示例：

```bash
cp .env.example .env
```

2. 编辑 `.env`，填入其一（勿提交 Git）：

```env
PUSHPLUS_TOKEN=你的token
# 或
# WECOM_WEBHOOK_KEY=你的key
```
