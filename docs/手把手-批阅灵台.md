# 手把手 · 批阅灵台

## 微信能批吗？

| 方式 | 能不能 |
|------|--------|
| 在微信通知里直接点「同意」 | **不能**（当前只是提醒，不是公众号菜单） |
| 微信里点开链接 → 手机网页点按钮 | **能** |
| 点完复制 → 回 **Cursor 姜子牙对话** 粘贴 | **能**（当前**没有**姜子牙微信号） |
| 暂存手机 | 可贴 **微信「文件传输助手」** 备忘，回家再粘 Cursor |
| 姜子牙把裁决写入诸神表 | 粘到 Cursor 或本对话说「听音」 |

## 怎么用（三步）

1. 微信收到「封神·待批」→ 点开里面的 **批阅灵台** 链接  
2. 每条下面点 **同意 / 退回 / 补充意见**  
3. 底部 **复制裁决** → 打开 **Cursor 里姜子牙这条聊天** 粘贴（PushPlus 微信只是提醒，不是姜子牙收件箱）
