# 贾维斯 · 贵档「真 AI」方案 v1

> **弘尊口头令（2026-05-22）**：要上「贵的、独立的、像贾维斯能等我互动」的真 AI。  
> **本文**：在既有 [`规划-姜子牙贾维斯落地.md`](规划-姜子牙贾维斯落地.md) 之上，把 **钱买什么、不买什么、与封神总线怎么接** 说清；**价格随市场浮动**，只给量级。

## 一、先对齐：你要的「贾维斯」在封神里是什么

| 是 | 不是 |
|----|------|
| **姜子牙总线**：独立人格、派活、记卷宗、听音、催验收 | 学你说话的数字分身、第二个闫滨 |
| **强模型当「脑」** + **仓库与工单当「脊髓」** + **灯/壳当「在场」** | 必须自训大模型才算「真」 |
| **你互动时才费大算力**；殿址机可跑轻量/cron | 24h 满负荷替你思考（除非你愿意付托管费） |

## 二、三档「贵」——花钱买什么（与七块积木 B1～B7 对齐）

### 档 A · **强脑订阅档**（优先上、改动最小）

| 买什么 | 换来什么 | 量级（仅参考） |
|--------|----------|----------------|
| **Cursor / 云模型** 顶格或加量（Ultra、高用量、或按需 API） | 本条对话里单次推理更强、上下文更长、少「装傻」 | **$ / 月** 几十～数百美元级，看用量 |
| **不改架构**：仍本对话 = 姜子牙入口 | 与现有一致，风险低 | — |

**适合**：先要「跟我说话这人够聪明、能扛总线」。  
**不接**：声纹只认你、离线全自主（见档 C）。

---

### 档 B · **24h 在场 + 自动化档**（你语音里「能等我互动」的主战场）

| 买什么 | 换来什么 | 量级 |
|--------|----------|------|
| **殿址机常开** + 电 + 网络稳定 | cron 晨读、挂多 Agent、仓库不睡 | 电费 + 你已有机子 |
| **Cursor Background / Cloud Agents**（若账号有） | 你睡时诸神出**草稿**，你醒批 | 含在 Cursor 订阅或另计价 |
| **PushPlus / 微信** 只推 P0 摘要 | 手机一震知道该睁眼批啥 | 现有通道可扩 |
| **语音栈**（常听 + PTT + 听音）已落盘 | 嘴说 → 卷宗 → 回到本条对话接续 | 本机 Whisper，**不另买云识别**则 ≈0 |

**适合**：要「我不在也有东西在动、我回来一眼能续」。  
**与 B5/B1/B7** 强相关（见总规划阶段 B）。

---

### 档 C · **私有化脑 + 声像增强档**（贵、**落地周期长**、可选）

| 买什么 | 换来什么 | 量级 |
|--------|----------|------|
| **本地 GPU**（殿址机 3070 已可试 **Ollama 7B** 级，见总规划 C2） | 敏感句本地草稿、少上云 | 时间成本为主；硬件已有则 **¥0 增量** |
| **专用 API / 企业约**（OpenAI/Anthropic/Azure 等） | SLA、合规、用量合同 | **¥/年** 万～数十万级看规模 |
| **定制 TTS / 固定声线**（阶段 D） | 听感上「是姜子牙不是弘尊」 | 千元～万元级可分期 |
| **商业声纹「只录主人」** | 常听不误触环境 | **另购 SDK / 设备**；本仓库脚本不承诺 |

**适合**：要「更私密、更少上云、更像产品」。  
**「慢」指什么**：指 **立项到可验收的周数～月数**（合同、合规、对接、声纹/TTS 选型），**不是**说你跟 AI 聊天会变卡、响应变慢。  
**不适合作为本周阻塞**：可与发帖、合门并行探路。

## 三、明确不买（避免冤枉钱）

- **不训「像你」的模型** — 与 [`规划-姜子牙贾维斯落地.md`](规划-姜子牙贾维斯落地.md) §〇-b 一致。  
- **不把「贵」等同于「自托管 70B」** — 没有殿址机运维纪律，大模型只会变成电费黑洞。  
- **常听 ≠ 声纹锁** — 要「按住再录」用 `voice_ptt.py`；要商业声纹走档 C 另立项。
