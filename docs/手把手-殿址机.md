# 手把手 · 殿址机诸神并行

> **对应**：立境者殿址机（Windows 台式机，可常开）。  
> 一次一步；做完回姜子牙 **「第 N 步好了」**。  
> **WPS / 不习惯 Markdown**：请用浏览器或 WPS 打开 **[手把手-殿址机.html](手把手-殿址机.html)**（与本文内容相同，不是苹果专有格式；`.md` 是 UTF-8 纯文本，任何编辑器都能开，WPS「文字」对 md 支持差，故另给 `.html`）。

---

## 这台机器干什么

- 开 **多个 Cursor Agent**（比干、吴道子、闻仲…）并行写 `deliverables/`  
- 跑 **柏鉴程序** `scripts/bailian_digest.py`（可选定时）  
- **不**要求 24h 空转：干完一批可关机，见 [排班与批次](../deliverables/张良/排班与批次.md)

---

## 第 1 步 · 装 Cursor

1. 浏览器打开 [https://cursor.com](https://cursor.com)  
2. 下载 **Windows** 版，安装，登录（与 Mac **同一账号** 即可）  
3. 打开 Cursor，能进主界面 → 回 **「Cursor 好了」**

---

## 第 2 步 · 装 Git

1. 打开 [https://git-scm.com/download/win](https://git-scm.com/download/win)  
2. 一路 **Next** 安装（默认即可）  
3. 开始菜单搜 **Git Bash**，打开，输入：

```bash
git --version
```

出现 `git version 2.x` → 回 **「Git 好了」**

---

## 第 3 步 · 克隆灵台

在 **Git Bash** 里（路径按你习惯改盘符）：

```bash
cd ~
git clone https://github.com/Corleoneyb/Jiangziyamemory.git
cd Jiangziyamemory
```

需要 GitHub 账号权限；克隆成功 → 回 **「仓库克隆好了」**

---

## 第 4 步 · 装 Python（柏鉴用）

1. 打开 [https://www.python.org/downloads/windows/](https://www.python.org/downloads/windows/)  
2. 装最新 **Python 3.12+**，勾选 **Add python.exe to PATH**  
3. Git Bash 里：

```bash
python --version
python scripts/bailian_digest.py
```

看到 `【柏鉴摘要】已写入 tasks/晨间裁决-...` → 回 **「柏鉴跑通了」**

---

## 第 5 步 · 自动 push（与 Mac 相同）

```bash
bash scripts/install-auto-push-hook.sh
```

---

## 第 6 步 · 开第一个神 Agent（比干示例）

1. Cursor → **New Agent**  
2. 首条粘贴：

```text
你是比干，读 @docs/agents/比干.md @tasks/诸神并行工单.md @deliverables/比干/
请改门v2文案和入门故事，落 deliverables/比干/，交付格式【比干交付】
```

3. 等它写完 → 回 **「比干 Agent 跑完一轮」**

再 **New Agent** 开吴道子（见 [开卷指令](../docs/agents/开卷指令.md) 扩神段，待补）。

---

## 可选 · 柏鉴每天 6 点自动摘要

Windows「任务计划程序」→ 每天 6:00 运行：

```text
python C:\Users\你的用户名\Jiangziyamemory\scripts\bailian_digest.py
```
