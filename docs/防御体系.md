# 防御体系 · 讨论稿

> 主人问：防恶意代码、黑客、仿造盗用、篡改……谁干？有没有必要？

**结论前置：有必要。** 灵台在公网（GitHub Pages）、有 Token、有树莓派，**不是封闭单机游戏**。

---

|----|------|------|
| **吕岳（警戒正神）** | **防御总司令**：威胁模型、权限、审计、事件响应 | ✅ Agent：`docs/agents/吕岳.md`（专会话待主人新建） |

## 二、威胁与对策（你要的「等等」）

### 1. 恶意代码

| 威胁 | 对策 |
|------|------|
| 仓库被植入后门 | 分支保护、PR 审查、闻仲不盲目 `curl \| bash` |
| 依赖投毒 | 锁定版本、定期 `npm audit` / 依赖审查（鲁班） |
| Pi 上恶意脚本 | 闻仲白名单路径；吕岳定「可执行目录」 |

### 2. 黑客攻击

| 威胁 | 对策 |
|------|------|
| GitHub Token 泄露 | 仅环境变量；`.gitignore` secrets；泄露即轮换 |
| 账号被盗 | GitHub/Gitee 2FA；独立强密码 |
| 树莓派暴露公网 | 非必要不暴露；SSH 密钥、改默认端口、防火墙 |

### 3. 仿造、盗用

| 威胁 | 对策 |
|------|------|
| 假灵台网站 | 只认官方 Pages URL；`docs/lingtai.md` 公示；HTTPS |
| 假姜子牙/闻仲 Agent | ADP 仅认主人账号；不轻信第三方 bot |
| 仓库 fork 冒名 | 官方链接写死；国史记「正库」地址 |

### 4. 数据篡改

| 威胁 | 对策 |
|------|------|
| 恶意改 `memories/` | Git 历史可回滚；敏感操作需主人或 Token |
| 见面台/API 被滥用 | Token 最小权限；rate limit（GitHub 侧） |
| 诸神幻觉写入假记忆 | 铁律：先确认；魔礼青验证；共卷审计 |

### 5. 内部与误操作

| 威胁 | 对策 |
|------|------|
| Agent 删库 | 闻仲白名单；禁止 `rm -rf` 无确认 |
| 主人误 push 秘密 | `git-secrets` 或 pre-commit 扫描（闻仲部署） |
| 备份失效 | Gitee 镜像 + 海康热备（柏鉴） |

## 三、防御分层（建议）

```
L1 铁律 + 验收（已有）— 防诸神与流程作恶
L2 吕岳 权限与威胁清单 — 防架构缺口
L3 闻仲 执行加固 — 2FA、分支保护、备份
L4 魔礼青 定期审计 — 对账 commit、异常登录
L5 柏鉴 备份与恢复演练 — 季度一次
```

## 四、有没有必要？

| 若不做 | 后果 |
|--------|------|
| 灵台裸奔 | Token 泄露 → 记忆被改或删 |
| Pi 裸奔 | 被当矿机或跳板 |
| 无审计 | 假完成、真篡改无法发现 |

**与你「信证据不信语气」一致** —— 防御不是可选装饰，是**吕岳神位存在理由**。
