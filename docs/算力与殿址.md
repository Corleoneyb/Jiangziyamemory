## 殿址机（已定 ✅）

| 项 | 配置 |
|----|------|
| CPU | Intel Core i7-11700 @ 2.50GHz（8C/16T） |
| 内存 | **32 GB** |
| 显卡 | **NVIDIA GeForce RTX 3070**（8GB VRAM） |
| 系统盘 | **WDS100T3X0C-00SJG0**（WD Blue SN NVMe，约 1TB） |
| 总存储 | 约 1.82 TB |
| 用途 | 游戏 + 封神殿址（共用） |

**能力**：串行殿议、Cursor、Git、树莓派 SSH、可选本地 7B～13B 量化模型（Ollama 等）；**不宜**打游戏时九神并行本地大模型抢显卡。
