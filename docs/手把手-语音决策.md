## 只录你、少录环境噪（实话）

- **常听**用的是 **VAD + 能量门槛**，能少误触，**不是声纹「只认你」**；本机脚本做不到苹果级「只响应主人」。  
- 要 **「按住才录、松开就停」**（最像「只在你有意说时才记」）：用 **`python3 scripts/voice_ptt.py`**（回车开始 / 回车结束）。  
- 常听仍误触：加参数 **`--peak-min 200`** 或 **`--min-speech-ms 1500`**；或关风扇、离键盘远点试。
