# 自动同步 · 少点「手动 push」

> 主人问：push 能不能自动，不用自己点？

---

## 已经自动的部分

| 环节 | 是否自动 |
|------|----------|
| **push 到 GitHub main 之后** → Pages 上线 | ✅ Actions `static.yml` 自动部署 |
| **push 到 main 之后** → 同步 Gitee | ✅ Actions `sync_to_gitee.yml` |
| **本地改文件** → 出现在网页上 | ❌ 须先 **commit + push** 到 GitHub |

瓶颈在：**Mac 本地 → GitHub** 这一步。

---

## 推荐：commit 后自动 push（一次配置）

在 Mac 终端（仓库目录）：

```bash
cd ~/Jiangziya/jiangziyamemory
./scripts/install-auto-push-hook.sh
```

之后：**每次 `git commit` 成功会自动 `git push`**（你或 Cursor 提交都算）。

**前提**：Mac 已配好 GitHub 凭据（SSH 或 credential helper），否则 push 仍会失败。

> `.git/hooks` 不进仓库；换电脑要再装一次。可让闻仲写 `scripts/install-auto-push-hook.sh` 一键安装。

---

## 不推荐（除非你很熟）

- **定时每分钟 auto-commit 整个目录**：容易把 `.env`、垃圾文件推上去  
- **网页里点「同步」**：`index.html` 的「手动同步」目前只是提示，不是真 push  

---

## 和 Cursor 协作

- 封卷时说：**「commit 并 push」** → 姜子牙代做 commit；若已装 hook，**push 自动**  
- 或装 **Cursor hook**（会话结束触发 push）——需要时再配

---

*灵台要新，先 push；push 要省事，用 post-commit。*
