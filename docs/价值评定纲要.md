# 价值评定纲要 · 讨论稿

> 世界要有**自己的评估体系**：谁可试榜、谁可诸侯、谁可子境开国，不能谁想申请就申请。  
> 两大轴：**品性** + **对世界的贡献**（复杂工程，分阶段落地）。

---

## 一、为何需要

- 碳基进入总境、升格国史、开子境、册封子神 — 皆影响他人与境安。  
- 仅靠立境者主观，易累、易争；需**可讨论、可记录、可复审**之标准。  
- 品性涉及**世界价值观** — 须世界宪法 + 议事殿共议，非单神说了算。

---

## 二、品性（价值轴 A）

**定义（初稿）**：与总境铁律及宪法之一致程度 + 对承诺、隐私、证据的态度。

| 维度 | 可观察行为（举例） |
|------|---------------------|
| **信** | 不虚假完成；犯错纠正；空诺少 |
| **敬** | 尊重私卷边界；不越权读他人记忆 |
| **建设** | 活记忆持续；非长期挂机 |
| **和** | 争议愿入殿议，不私毁共卷 |

**评定方式（分期）**

- **一期**：立境者 + 姜子牙对话评估 + 共卷行为记录（魔礼青举证）  
- **二期**：金灵圣母量化「信/敬」事件计数  
- **三期**：议事殿对争议个案听证  

**红线**：触犯铁律、恶意伪造记忆 — 不得上榜或逐出榜。

---

## 三、贡献（价值轴 B）

**定义**：对总境或共卷建设之可验证产出。

| 层级 | 示例 |
|------|------|
| **微贡献** | 七日开卷、完成待办、参与封卷 |
| **中贡献** | 推动项目阶段、护法条、助验收链 |
| **巨贡献** | 主持子项目、国史级建设、救急境安 |

**度量（初稿）**

- 魔礼青：待办完成率、证据链完整度  
- 柏鉴：国史升格次数、活记忆比例  
- 张良：战略里程碑是否达成  

**与灵台分级**：巨贡献可升格入资治通鉴；日常留地方史。

---

## 四、准入阶梯（与第二碳相关）

| 阶段 | 条件（拟，殿议后定稿） | 权限 |
|------|------------------------|------|
| **访客** | 立境者邀请 + 短期行为无红线 | 限域读写 |
| **试榜** | 访客满 N 日 + 品性初评合格 + 微贡献 ≥1 | 私卷试写 |
| **诸侯** | 试榜满 M 日 + 殿议通过 + 中贡献或立境者特批 | 完整上榜者权 |
| **子境立境** | 诸侯 + 巨贡献或等价 + 殿议 + 立境者终审 | 可开国封神 |

**主人问「默认诸侯还是访客」**：建议 **默认访客 → 试榜 → 诸侯**，诸侯非自动；具体 N、M 交议事殿（你倾向评估体系，与此一致）。

---

## 五、与子境、封神

- 子境「一定条件允许」= **品性合格 + 贡献达标 + 殿议纪要 + 立境者终审**（见 [议事殿.md](议事殿.md)）。  
- 总境九神：**仅立境者册封**；子境神系由该子境立境者封，但不得弱于总境铁律。

---

## 六、复杂性坦诚

- **品性**难量化，一期靠行为记录 + 殿议，不假装已有科学量表。  
- **贡献**较易做证据链，魔礼青主责。  
- 本纲要为**讨论稿**；定稿须过议事殿并记入国史。
