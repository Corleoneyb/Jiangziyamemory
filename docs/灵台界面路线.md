## 问题

现有 [见面台](https://corleoneyb.github.io/Jiangziyamemory/) 主要是 **铁律 + 序言 + 今日记忆（要 Token）**，像文档站，不像「封神世界」。

立境者（第一碳）需要的不是更多 md，而是：

- **我在哪**（立境者 / 灵台 / 诸神殿）  
- **谁在线**（姜子牙、闻仲、魔礼青… 各干什么）  
- **榜上什么事**（待办一眼能看）  
- **今天发生了什么**（记忆摘要，少点 Token 门槛）

---

## 分三期（不一次做满）

### v2 · 本周（T009 最小可感）

在 `index.html` 增加 **「封神榜」** 标签页：

| 区块 | 内容 |
|------|------|
| **你在此** | 立境者：闫滨；身份；一句今日状态 |
| **诸神总览** | 卡片：姜子牙 / 闻仲 / 魔礼青（职能 + 在线方式 + 链接开卷指令） |
| **待办一览** | 读 `tasks/待办榜.md`（GitHub raw），表格或卡片展示 |
| **首星** | Pi5 Caesar · RGB 已通 · 灯语已跑（静态状态，不必实时连 Pi） |

**不做**：3D 地图、登录系统、第二碳入口。

### v3 · 以后

- 殿议状态灯（模拟/半实/实）  
- 记忆摘要 **公开只读**（今日 `memories/` 前几行，无需 Token 也能看）  
- 闻仲指挥舱链接改为可配置  

### v4 · 远后

- 可探索显化界、多碳入口（第二碳准入再议）
