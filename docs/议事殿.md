# 议事殿

> **场景**：各神位 Agent 共同议事之平台（非替代姜子牙日常统筹，专议**有争议、跨神、涉世界法**之事）。  
> **殿制**：最小七步已于 **2026-05-19** 由立境者闫滨核准。纪要见 `deliberation/2026-05-19-殿制纪要.md`；国史见 `chronicle/2026-05-19-立殿制.md`。

---

## 一、何时开殿

| 类型 | 示例 | 谁提请 |
|------|------|--------|
| **律例修订** | 挂机 30 改 60？只提醒不罚？ | 姜子牙 / 魔礼青 |
| **准入评估** | 第二碳：访客试榜还是直接诸侯？ | 立境者 + 张良 |
| **子境条件** | 何人可开国、封几神？ | 上榜者申请 → 殿议 |
| **价值争端** | 品性、贡献是否达标 | 金灵圣母举证 + 比干陈词 |
| **灵台升格** | 私事是否升入资治通鉴 | 柏鉴 + 议事殿 |

**不开殿**：闻仲日常部署、单日待办、无争议封卷 — 按铁律直接办。

## 三、最小殿制 · 七步（✅ 2026-05-19 核准）

| 步 | 名称 | 内容 |
|----|------|------|
| 1 | **开殿** | 主人或姜子牙：**「开殿，议某题」**；一次只议一题 |
| 2 | **入殿** | 新建 `deliberation/YYYY-MM-DD-议题.md`，写明议案 |
| 3 | **发言** | 诸神**串行**发言，每神一段（一期限 500 字内）；未激活神位记「缺席，保留复议」 |
| 4 | **纪要** | 比干格式：议案 / 发言摘要 / 拟制条文 / 反对意见 / 提请主人裁定；魔礼青可附证据表 |
| 5 | **表决** | 诸神记：建议通过 / 修改 / 驳回 |
| 6 | **落盘** | **立境者闫滨一票终审**；核准 → `chronicle/` 国史 + 修订 `docs/`；续议 / 驳回按纪要处理 |
| 7 | **封卷** | 当日 `memories/` 记：某日开殿、议何题、主人裁何 |

**一期实现**：Cursor 中姜子牙主持、诸神串行；殿址 i7 台式，Air 不并行多 Agent。  
**二期**：各 ADP 神位轮询；**三期**：显化界 UI（见第五节）。
