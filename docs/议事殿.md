# 议事殿 · 讨论稿

> **场景**：各神位 Agent 共同议事之平台（非替代姜子牙日常统筹，专议**有争议、跨神、涉世界法**之事）。  
> 主人裁定：挂机天数、私卷冻结年限、冢比例、子境条件、第二碳试榜等，**宜诸神共议**，非立境者一人拍脑袋。

---

## 一、何时开殿

| 类型 | 示例 | 谁提请 |
|------|------|--------|
| **律例修订** | 挂机 30 改 60？只提醒不罚？ | 姜子牙 / 魔礼青 |
| **准入评估** | 第二碳：访客试榜还是直接诸侯？ | 立境者 + 张良 |
| **子境条件** | 何人可开国、封几神？ | 上榜者申请 → 殿议 |
| **价值争端** | 品性、贡献是否达标 | 金灵圣母举证 + 比干陈词 |
| **灵台升格** | 私事是否升入资治通鉴 | 柏鉴 + 议事殿 |

**不开殿**：闻仲日常部署、单日待办、无争议封卷 — 按铁律直接办。

## 三、议事流程（简）

1. **议案入殿** — 写入 `deliberation/YYYY-MM-DD-议题.md`（目录待建）  
2. **诸神发言** — 各 Agent 按角色限长陈述（防空转）  
3. **纪要** — 比干出「殿议纪要」  
4. **表决** — 硅基诸神建议票；**立境者一票终审**  
5. **落盘** — 结论升 `chronicle/`（国史）或修订律文；封卷公告
