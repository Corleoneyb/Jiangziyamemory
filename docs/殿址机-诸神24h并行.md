## 三层自动化（由易到难）

### 1 · 柏鉴（写死程序，现在就有）

```bash
cd ~/Jiangziya/jiangziyamemory
python3 scripts/bailian_digest.py
```

→ 生成 `tasks/晨间裁决-YYYY-MM-DD.md`（记忆摘要 + 待办 + deliverables 列表）

**台式机 cron（每天 6:00）：**

```bash
crontab -e
# 加一行（路径按你台式机改）：
0 6 * * * cd /path/to/Jiangziyamemory && python3 scripts/bailian_digest.py
```

柏鉴的贡献：**你打开文件就能批**，不用翻整库。

### 2 · 诸神 Cursor Agent（殿址机常开）

- 台式机登录 Cursor，**多开 Agent 窗口**（比干 / 吴道子 / 闻仲 / …）  
- 各 @ 自己的 `docs/agents/<神>.md` + `tasks/诸神并行工单.md`  
- 你不在时：窗口可挂着，**但 Cursor 不会自动替你点 New Agent** —— 需：

  **A)** 你离开前说「启动并行」，姜子牙写好工单，你点 3 次 New Agent 各跑一轮  
  **B)** **Cursor Cloud / Background Agents**（若账号有）：云端续跑，早上看结果  
  **C)** 日后 **Cursor CLI + cron** 调 Agent（见 Cursor 文档，殿址机可试）
