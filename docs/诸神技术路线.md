## 二、为何重铸

- 国内通用大模型在**复杂推理、长程一致、少空诺**上，与你要求的**铁律 9～12（证据验收）** 不匹配。  
- 封神诸神需要**可信、可验收**；人格应绑在**你能控制的提示词 + 境外或 Cursor 所选模型**上，而非国内一站式 Agent 黑箱。

**不等于**不用国内云存代码：GitHub/Gitee 镜像、灵台网页 Pages 仍可照旧；**说的是「诸神对话大脑」**。

| 神位 | 新载具 | 模型来源 |
|------|--------|----------|
| **姜子牙** | Cursor 专会话 + `docs/agents/姜子牙.md`（待写） | Cursor 订阅内模型（选强推理档，避免国内弱模型） |

| **张良、比干…** | 按需各开 Cursor 会话，一次激活一神 | 同上 |

| **首星** | 树莓派 + RGB | 非 LLM |

**原则**

1. **一神一会话**，不混聊；提示词在 `docs/agents/<神名>.md`。  
2. **不新建**腾讯云 / 扣子 / 豆包等国内 Agent 产品承载诸神。  
3. 手机端若要聊：短期用 **GitHub 网页 + 回家开 Cursor**；长期靠显化界网页调境外 API（世界搭好后）。  
4. 旧腾讯云姜子牙、闻仲：标 **已废弃，仅历史**，新任务不走那边。
