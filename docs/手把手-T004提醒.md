## 你需要准备

## 第 1 步 · 注册 PushPlus（约 10 分钟）

1. 浏览器打开：**https://www.pushplus.plus/**
2. 用微信扫码登录（按网页提示）。
3. 进入 **「一对一推送」** 或 **「发送消息」** → 找到你的 **token**（一长串字符）。
4. **复制 token**，先粘到备忘录，不要发给任何人。

> 若你更想用企业微信群：用企微机器人 webhook 的 `key=` 后面那段，填 `WECOM_WEBHOOK_KEY`（见 `.env.example`）。下面以 PushPlus 为例。

- [ ] 我已复制 PushPlus token

---

## 第 2 步 · 写本地 `.env`（约 3 分钟）

1. 打开 Cursor，确认项目是 **`Jiangziyamemory`** 根目录。
2. 终端执行：

```bash
cd ~/Jiangziya/Jiangziyamemory
cp .env.example .env
```

3. 用 Cursor 打开 **`.env`**（根目录，左侧或 `Cmd+P` 输入 `.env`）。
4. 改成（把 `你的token` 换成真实 token，不要引号外的空格）：

```env
PUSHPLUS_TOKEN=你的token
```

5. **保存**。`.env` 已在 `.gitignore`，**不会**被 push 上去。

## 常见错误

| 现象 | 处理 |
|------|------|
| exit 2 未配置 | 检查 `.env` 是否在仓库**根目录**，token 无空格无引号 |
| 网络错误 | 开 VPN 后再跑脚本 |
| 手机没收到但 API 200 | 看 PushPlus 网页发送记录；换微信是否绑定 |
| token 泄露 | 在 PushPlus 后台重置 token，改 `.env` |
