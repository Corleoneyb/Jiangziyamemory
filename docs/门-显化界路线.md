## 门 v0.1 长什么样（最小「进了另一个世界」）

不追求 3D 绿洲，但要 **心理切换**：

1. **全屏**：深色、星尘/微光，一句：**「封神世界」**  
2. **一个主按钮**：**「进入」**（或「踏入门内」）  
3. **点进后**（第二屏，仍是网页）：  
   - **诸神殿**：姜子牙 / 闻仲 / 魔礼青 卡片（职能 + 状态）
