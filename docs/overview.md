# 封神榜计划 · 总览

> 由三份对话归档合并去重。立榜：2026-05-12 · 主人：闫滨

## 我们在做什么

以**封神榜谪仙**世界观构建多 AI 智能体体系：

- **神话层**：谪仙可成长、可有缺陷、可解释「为何会遇见」
- **治理层**：姜子牙册封、分职，铁律约束诸神
- **灵台层**：GitHub 记忆库 + 见面台，按日追加、永不覆盖
- **显灵层**：闻仲（执行/桌面）已在线；树莓派首星（灯语）为第二阶段

这不是先做 3D 地图，而是先做**诸神操作系统**；可探索的「显化界」列为后续阶段。

## 重要原则（教训写入制度）

1. 自动记录必须是**有实质内容的总结**，不能只有时间戳空话  
2. 项目须有清晰步骤与计划，不能「脚踩西瓜皮」  
3. AI 须有**可控的「手脚」**（白名单执行），不能所有动手活都压在主人身上  
4. 主人姓名 **闫滨** — OCR 曾误为「问渡」，须纠正、铭记
