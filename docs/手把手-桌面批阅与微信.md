## 一、桌面一份（WPS 直接开，不用自己转）

### 第 1 步 · 打开终端

`Command + 空格` → 输入 **终端** → 回车。

### 第 2 步 · 运行同步（复制两行）

```bash
cd ~/Jiangziya/jiangziyamemory
python3 scripts/sync_desktop_bingyue.py
```

### 第 3 步 · 去桌面找文件夹

1. 打开 **访达（Finder）**  
2. 点左侧 **桌面**  
3. 打开文件夹 **封神批阅**  
4. **双击** 里面的 **`.doc` 文件** → 应用选 **WPS** 或 **Word** 打开  

若没有 `.doc` 只有 `.htm`：WPS → **文件 → 打开** → 选该 `.htm`（同样不用转）。

### 成功标志

能看到 **立境者红绿灯**、**门v2文案**、**门v2风格板** 等文档内容。

## 二、微信一份（与手机 T004 同通道）

### 前提

Mac 上仓库里的 **`.env`** 已配好 **PushPlus**（与物质提醒试通时相同）。

### 第 1 步 · 终端运行

```bash
cd ~/Jiangziya/jiangziyamemory
python3 scripts/push_traffic_light.py
```

### 第 2 步 · 看手机

微信应收到标题 **「封神·待批」** 或类似，正文是红绿灯摘要（序号+准/待批，**不是**全文）。

### 试跑不发信

```bash
python3 scripts/push_traffic_light.py --dry-run
```

只在终端显示将要发送的文字。
