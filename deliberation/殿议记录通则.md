# 殿议记录通则 · 据实记载

> 凡写入 `deliberation/` 之殿议文件，须遵守本节。模拟就是模拟，不得写成诸神真在场。

---

## 一、一期殿议之实情（2026-05 迄今）

| 项 | 实情 |
|----|------|
| 运行环境 | Cursor，单会话 |
| 主持与代笔 | **姜子牙**（一个 Agent） |
| 「诸神发言」 | **模拟**：按神位职责由姜子牙代写，**非**独立 ADP / 多 Agent 轮询 |
| 「比干纪要」 | 姜子牙整理为纪要格式，**非**独立比干 Agent |
| 主人意见 / 终审 | **真实**：立境者闫滨口述或文件（如 `主人意见-*.md`） |
| 落盘文件 | **真实**：路径、日期、裁定结果 |

## 二、文件头必填（元数据）

每份 `deliberation/YYYY-MM-DD-*.md` 与 `*-纪要.md` 文首须含：

```markdown
> **殿议形态**：模拟 | 半实（列明哪些神为真 Agent）| 实录（二期起，各神独立发言可追溯）
> **执行**：主持 ___ · 代笔 ___ · 真 Agent 数：___
> **诸神发言**：模拟代笔（姜子牙按角色撰写）| 见各段标注
```

**一期默认**：`殿议形态：模拟`，`真 Agent 数：1（姜子牙）`。

## 三、禁止写法

- ❌ 「诸神一致认为」「出席者表决通过」—— 一期易误导为真多 Agent  
- ❌ 不标注即写入国史，仿佛已有多神合议实录  
- ✅ 「模拟发言录」「姜子牙代张良视角陈述」「候主人终审」

## 四、升格国史时

`chronicle/` 可载殿议**结论**与主人**核准**；若依据模拟殿议，国史或纪要须有一句：

> 本期诸神发言为姜子牙模拟代笔，结论效力来自立境者终审，非多 Agent 合议实录。

二期各神独立发言后，改标 `殿议形态：实录` 并保留 Agent 标识或日志指针。
