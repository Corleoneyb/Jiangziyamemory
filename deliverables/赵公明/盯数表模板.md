## 盯数表（写入 memory 的 Markdown 表）

**列定义（T010 脚本须一致）**

| 列 | 类型 | 说明 |
|----|------|------|
| **时点** | 文本 | 如 `2026-05-23 14:00` 或 `发后+6h` |
| **评论** | 整数或 `—` | 可见评论条数（脚本 Pull/Playwright 读页） |
| **私信** | 整数或 `—` | 私信条数（若页不可读则 `—` + 备注） |
| **问价** | 是/否/`—` | 是否有人问价或愿付 ¥49 |
| **备注** | 文本 | 来源 `auto`/`manual`、脚本名、失败告警 id 等 |

**可选扩展列（脚本 JSON 可带，memory 表可并入备注）**：`来源` · `脚本` · `累计评论` · `累计私信`

```markdown
| 时点 | 评论 | 私信 | 问价 | 备注 |
|------|:----:|:----:|:----:|------|
| （T010 首次 auto 写入） | | | | |
| （T010 第二次 auto 写入） | | | | |
```
