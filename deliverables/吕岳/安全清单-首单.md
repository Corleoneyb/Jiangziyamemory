# 安全清单 · 首单

> **吕岳**（警戒正神）· 威胁面与密钥约束一页。下文**不写任何密钥真值**。

## 1. 密钥类（只列名与位置）

### 1.1 环境变量（代码直读）

| 变量名 | 用途（简述） | 应存放 |
|--------|--------------|--------|
| `PUSHPLUS_TOKEN` | PushPlus 一对一推送 | 仅本机：仓库根目录 `.env`，或进程环境；**勿入库** |
| `WECOM_WEBHOOK_KEY` | 企业微信机器人 webhook 的 `key=` 段 | 同上 |
| `WHISPER_MODEL` | 本地语音转写模型名（默认 `small`） | `.env` 或本机环境均可；**非密钥**，可按需共享名称 |

**原则**：凡带 Token / Key / Webhook 字样的值，**应只在 `.env` / 本机环境**，与 `docs/提醒通道.md` 一致。

### 1.2 配置文件中的敏感项（非 env，同等对待）

`wenzhong/config.yaml`（闻仲侧树莓派部署）内常见敏感键路径（**只列路径，不写值**）：

- `deepseek.api_key`
- `github.token`
- `wenzhong.auth_token`

存放：仅部署机本机文件；**勿**将含真值的 `config.yaml` 提交到 Git。

### 1.3 CI 与远端

- GitHub Actions 使用 `secrets.GITEE_TOKEN` 等：仅在仓库 **Settings → Secrets** 配置；日志与 PR 描述中不得粘贴。

## 2. 禁止入库

以下**不得**进入版本库（与 `.gitignore` 及诸神铁律一致）：

| 模式 | 说明 |
|------|------|
| `.env` | 本地密钥与通道配置 |
| `.env.*` | 环境变体文件（本仓库已忽略） |
| `*.pem` | 私钥与证书私钥材料 |
| `credentials*` | 各类凭据文件名惯用前缀 |
| `*.token`、`*_token*`、`secrets/` | 本仓库 `.gitignore` 已列出的扩展规则 |

**闻仲落地**：合并前跑 `git status`，确认无上述文件被误 `git add`。

## 3. 外发前脱敏检查（白话）

### 发帖（群 / 论坛 / 动态）

1. 文中是否出现 **Token、API Key、Webhook 整段 URL、私钥 PEM 块**？有则删掉或改成「已配置在本机」。
2. 截图里的**终端、编辑器、浏览器地址栏**是否带 query 里的 `key=`、`token=`？有则裁切或打码。
3. 是否复制了**整份 `.env` 或 `config.yaml`**？只发结构示例时用占位符（如 `你的token`），与文档示例一致。

### 截图

1. **桌面 / 任务栏**是否露出其它聊天窗口、邮箱、密码管理器？能裁则裁。
2. **IDE 左侧文件树**是否点开 `.env`、`config.yaml`、`*pem`？发前关闭或打码文件名与内容区。
3. **系统设置 / Wi‑Fi 密码 / 蓝牙设备名**是否与个人身份强绑定且非必要？非必要不打进图。

3. **后半段是否切到终端 `cat .env` / `printenv`**？剪辑掉或全程避免执行此类命令。
