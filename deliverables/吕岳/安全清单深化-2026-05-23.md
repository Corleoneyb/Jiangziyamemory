## 1. 合并前敏感路径漏检

| 维度 | 内容 |
|------|------|
| **谁做** | **闻仲**（每次 `git commit` / `git push` 前自跑）；**魔礼青**在验「闻仲交付 / 含 push 的待办」时对账本条输出 |
| **落哪** | ① 命令与说明写入 `tasks/闻仲-安全合并自检.md`（闻仲首跑时建）；② 每次大提交或弘尊点名验收时，**一行证据**写入 `deliverables/闻仲/安全合并自检-YYYYMMDD.md` 或当日 `memories/YYYY-MM-DD.md`（只贴命令输出摘要，**禁止**贴 token 真值） |
| **怎么做** | 在仓库根目录执行（可复制进闻仲工单）： |

```bash
# A. 已跟踪文件不得含敏感路径
git ls-files | grep -E '(^\.env$|\.env\.|\.pem$|credentials|secrets/)' && echo 'FAIL: 敏感路径已入库' && exit 1 || echo 'OK: 无敏感路径入库'

# B. 暂存区不得出现 KEY= 真值行（示例行 sk-/ghp_ 占位除外，真值须为 x 占位）
git diff --cached | grep -E '(PUSHPLUS_TOKEN|WECOM_WEBHOOK_KEY|api_key:|auth_token:).*(sk-[a-zA-Z0-9]{8,}|ghp_[a-zA-Z0-9]{8,})' && echo 'FAIL: 暂存区疑似真密钥' && exit 1 || echo 'OK: 暂存区无疑似真密钥'
```

| **怎么验** | 魔礼青 / 姜子牙打开落盘证据，须同时满足：① 输出含 `OK: 无敏感路径入库` 与 `OK: 暂存区无疑似真密钥`；② **无** `.env` / `*.pem` 出现在 `git ls-files` 列表；③ 若任一条 `FAIL`，该次合并 **不得 push**，闻仲删暂存敏感文件后重跑直至双 OK |

## 2. 提醒通道 `.env` 本机配置与试通

| 维度 | 内容 |
|------|------|
| **谁做** | **弘尊**（碳基）：在仓库根创建 `.env`，只填变量名对应值（见首单 `PUSHPLUS_TOKEN` 或 `WECOM_WEBHOOK_KEY` 二选一即可）；**闻仲**跑试通命令并记结果 |
| **落哪** | ① 真值文件：仅本机 `jiangziyamemory/.env`（**永不** `git add`）；② 操作说明已有：`docs/如何编辑-env.md`、`docs/提醒通道.md`；③ 试通证据：**一行**写入 `memories/YYYY-MM-DD.md` 或 `deliverables/闻仲/T004提醒试通.md`，格式示例：`fengshen_remind.py exit=0，通道=PushPlus，未落盘 token` |
| **怎么做** | 弘尊按 `docs/如何编辑-env.md` 编辑 `.env` 后，闻仲执行：`python3 scripts/fengshen_remind.py`（脚本已从 `.env` 读密钥，见 `scripts/fengshen_remind.py`） |
| **怎么验** | ① 命令 **exit code = 0**；② `git status` 显示 `.env` 为 **untracked 或 ignored**，且 **不在** `git ls-files`；③ 证据行 **不出现** `PUSHPLUS_TOKEN=` / `WECOM_WEBHOOK_KEY=` 后的真值；④ 若 exit=2，记「未配置」并催弘尊补 `.env`，**不**在仓库内写占位真密钥 |

## 3. 外发帖 / 截图脱敏勾选落盘

| 维度 | 内容 |
|------|------|
| **谁做** | **弘尊**（碳基发帖/截图前勾选）；**赵公明线**在 G1 发帖回执时 **督促**本条落盘；**姜子牙**听榜时 spot check；**魔礼青**验 G1 证据时顺带验脱敏行 |
| **落哪** | 每帖一行，写入 `tasks/赵公明范蠡-发帖工单.md` 的 **「发帖执行记录」** 表，或当日 `memories/YYYY-MM-DD.md` 发帖段；字段固定为：`脱敏✓ YYYY-MM-DD` + 勾选站名（即刻/V2EX/其它） |
| **怎么做** | 发帖或发截图前，对照首单 §3 对应小节 **3 条**各答「是/已处理」： |

**发帖（3 条）**

- [ ] 正文无 Token / API Key / 带 `key=` 的完整 Webhook URL / PEM 块  
- [ ] 附图无终端、地址栏、编辑器中的密钥  
- [ ] 未粘贴整份 `.env` 或含真值的 `config.yaml`  

**截图（3 条）**

- [ ] 已裁掉无关聊天窗、邮箱、密码管理器  
- [ ] 文件树未展开 `.env`、`config.yaml`、`*pem`  
- [ ] 无多余 Wi‑Fi/系统身份暴露  

落盘时在发帖记录后附一句：`脱敏：发帖3/截图3 已勾`（录屏帖另勾首单 §3 录屏 3 条，写法 `脱敏：录屏3 已勾`）。

| **怎么验** | 魔礼青 / 姜子牙查 G1 同条记录：① 有 `脱敏✓` 日期；② 弘尊提交的截图/链接路径（若存仓）**目视**无首单 §3 所列泄露；③ 缺 `脱敏✓` 行 → G1 **不得**标「可验盯数」，催赵公明线补勾后再进盯数 |
