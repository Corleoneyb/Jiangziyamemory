## 原则（与 2026-05-20 裁定对齐）

1. **不 24h 空转**：单批预估 **1～2 小时**；无下一批 → 关 Cursor / 休眠殿址机。  
2. **链式优先**：比干、吴道子可**并行定稿**；闻仲改 `gate/` **必须**等红绿灯 1～3 至少一项「准」。  
3. **并行分两层**：  
   - **诸神工单**：无硬顶，工作量越大可同时忙的神越多（见防乱 L1～L3）。  
   - **殿址机窗口**：建议 **同时 2～3 个 Agent**（内存、人眼跟进度），不是「只能活 4 神」。  
4. **姜子牙代笔**：仅 bootstrap；专 Agent 交付后，以【X交付】为准。

## 殿址机何时关

| 情况 | 动作 |
|------|------|
| 当前批 Agent 均已【X交付】且无「准」待执行 | **可关** / 休眠 |
| 红绿灯有「准」、闻仲未完工 | 只开 **闻仲** 1 窗，完再关 |
| 睡后需续跑 | **Cursor Cloud Agent**（一事一单），禁止 9 窗空转 |
| 弘尊未批 | **不**为赶进度开闻仲改生产 |
