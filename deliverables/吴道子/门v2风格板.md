## 一、设计意图

| 维度 | v0.1（现状） | v2 目标 |
|------|-------------|---------|
| 心理 | 深色页 + 按钮 | **进门像进影院**：门外静、门内活 |
| 纵深 | 单层星尘 `drift` | **远星 / 中雾 / 近暗角** 三层 |
| 仪式 | 金字 + 金按钮 | **门框剪影** + 门环按钮 + 0.6s 暗场过渡 |
| 叙事 | 副标题一行 | 对齐比干：**「另一扇门」** + 殿内引言块 |
| 进入 | splash `opacity` 0.9s | **暗场 0.35s → 界内自下方 24px 上浮**（与故事「慢慢浮出」同拍） |

气质一句：**虚夜为幕，封神金为灯，翠青琥珀为诸神色；灵台在角，门在中央。**

## 四、过渡 · 「暗场再浮世」

比干故事：铃轻 → **光慢慢浮出**。实现拆两段：

```css
/* 1) 门外退场：先压暗，再隐 */
#splash.leaving {
  transition: filter 0.35s ease, opacity 0.5s ease 0.15s, visibility 0.5s ease 0.15s;
  filter: brightness(0.35);
}
#splash.hidden {
  opacity: 0;
  visibility: hidden;
  pointer-events: none;
}

/* 2) 界内入场 */
#world {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity var(--dur-world-in) var(--ease-out) 0.2s,
              transform var(--dur-world-in) var(--ease-out) 0.2s;
}
#world.visible {
  opacity: 1;
  transform: translateY(0);
}
```

JS：`enterWorld()` 先给 `#splash` 加 `leaving`，`setTimeout(350)` 后再 `hidden` + `#world.visible`（与 chime 同时触发）。

## 七、音效方向（Web Audio + 可选 mp3）

### 7.1 进入铃（保留三音，加铺底）

| 参数 | v0.1 | v2 |
|------|------|-----|
| 音高 | C5–E5–G5 sine | 同序，**triangle** 主音 + sine 叠 0.3 音量 |
| 音量 | peak ~0.06 | peak **0.05**，总时长 **1.4s** |
| 铺底 | 无 | 进入同时 **55Hz** 低通，`gain` 0 → 0.012，**0.8s** 淡入（接现有 ambient） |

```javascript
// 闻仲：playEnterChime 末加一行 startSubBass(t)
function startSubBass(ctx, t) {
  const o = ctx.createOscillator();
  const g = ctx.createGain();
  const f = ctx.createBiquadFilter();
  o.type = 'triangle';
  o.frequency.value = 55;
  f.type = 'lowpass';
  f.frequency.value = 90;
  g.gain.setValueAtTime(0, t);
  g.gain.linearRampToValueAtTime(0.012, t + 0.8);
  o.connect(f); f.connect(g); g.connect(ctx.destination);
  o.start(t); o.stop(t + 4);
}
```

### 7.2 环境声

| 方案 | 文件/实现 | 说明 |
|------|-----------|------|
| A（零素材） | 现有 55Hz sine + LP | v0.1 已有，`gain` 降至 **0.012** |
| B（推荐） | `gate/assets/ambient_gate.mp3` | 循环 · **-24 LUFS** 目标 · 30–60s 无缝 · 进入后 `fadeIn 1.2s` |
| C（远） | 殿议/终审 | 暗蓝垫 / 暖橙垫，与 RGB 同调，v3 |

**mp3 命名建议**（闻仲落 `gate/assets/`）：

- `enter_chime.mp3` — 0.8s，可选替代 Web Audio  
- `ambient_gate.mp3` — 门内环境循环  
- `ambient_gate_dark.mp3` — 殿议态（v3 预留）
