## 一、总规范

| 项 | 统一规则 |
|----|----------|
| 画布 | `80 × 96`，`fill="none"` |
| 脚底 | 椭圆 `cx="40" cy="88" rx="28" ry="6"`，填诸神色 20–25% opacity |
| 描边 | `stroke-width="1"`～`1.2`，颜色 = 诸神专色 |
| 填充 | 深紫灰 `#1a1828`～`#222838` 分神微调 |
| 容器 | `.portrait` 72×88 → v2 建议 **80×96** 与 viewBox 1:1 |
| hover | `.card:hover .portrait { transform: scale(1.04); filter: drop-shadow(0 0 16px var(--glow)); }` |
| 无障碍 | `aria-hidden="true"` 保留，名字在 `.name` |

**诸神色与 glow 变量**

| 神 | 描边/强调 | glow（卡片 CSS 变量） |

| 姜子牙 | `#c9a96e` | `rgba(201,169,110,0.4)` |
