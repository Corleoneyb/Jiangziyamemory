## 即刻 / V2EX：没有账号能发帖吗？

| 问 | 答 |
|----|-----|
| **没账号能发主帖吗？** | **不能。** 两站 **发帖**都要先 **注册账号**（按各站当时规则：手机/邮箱等）。没有「零账号发长帖」的常规路径。 |
| **游客能干嘛？** | 一般只能 **看**，发帖/评论权限很窄或没有。 |
| **怎么办？** | **各站注册 1 个号**（可用 **小号**，不必真名），专门发试水帖；与灵台仓库、封神代号 **脱钩**。注册、收验证码、发帖按钮 **只能弘尊本人或你委托的真人** 操作。 |
| **两站都要发？** | 可以：即刻一个号、V2EX 一个号（或同一邮箱各注册），**各发 1 篇**，勿同文复制。 |
| **赵公明/范蠡会去注册小号吗？** | **不会。** 专窗是 **写稿、口径、记数、清单**；**没有**平台账号、**不能**代过人脸/手机实名。 |

> 具体注册按钮以各站 App/网页为准；赵公明/范蠡专窗可写 **「注册逐步清单」**（给你照着点）进 `memories/` —— 仍是 **你动手**，不是 AI 替你注册。

## 流程闸门 G0：账号 / 工具已就绪（发帖前置）

> **原先漏洞**：流程里若**不先核实**各站是否已有**可发帖账号**，就会像魔礼青验收时**交付方未交证据**——闻仲没材料、魔礼青验不下去；这里同理：**没账号就没工具**，不能假装已进入发帖执行。本闸门补上这一节点。

**硬顺序（不可跳）**：**G0 落盘** → 执笔定渠道 + 弘尊帖准 → **发帖** → **G1 发帖回执落盘** → 赵公明线盯数（48h ≥2 次）→ **魔礼青验盯数证据**（可选一事一填，见文末）。

| 闸门 | 谁举证 | 谁核实 / 落盘 | 证据形式 | 未满足时 |
|------|--------|----------------|----------|----------|
| **G0** | **弘尊**（碳基）：拟发帖的每一站**已有**可发帖账号（或明确本周**只发一站**） | **赵公明线**：专窗或当日 `memories/` **一行状态**（已就绪 / 缺哪站 / 只发何处） | 在本条 Cursor 对话里口头确认即可；**禁止**把密码写进仓库 | **不执行发帖**；状态标 **缺即刻 / 缺 V2EX / 待注册** 直至 G0 闭合 |

## 即刻盯数 · 自动化（弘尊 2026-05-23）

> 铁律全文：`docs/弘尊铁律-自动化优先.md` · 执行工单：`tasks/赵公明-即刻盯数自动化.md`

### 现状（诚实说明）

| 事实 | 说明 |
|------|------|
| Cursor / 灵台 | **不能**自己登录弘尊的即刻 App |
| 赵公明 Agent 专窗 | **不会**自动收到即刻 App 推送；聊天窗口**不等于**盯帖机器人 |
| 「开个赵公明聊天」 | **不能**实现自动盯数，最多人工复制数字进 memory |
| 要实现自动盯 | 必须**工程化**：本机定时脚本、Playwright、或 Pull 公开页（若无需登录可读） |

### 弘尊只动手几次

1. **首次**登录即刻 / 扫码（或 cookie 写入供 Playwright 用）  
2. **cookie 过期时**补登录一次  
3. **露脸回评论**、**裁决**卖不卖 / 价未定怎么说  
4. 发帖当周：**看稿准发** + **G1 举证**（站、标题、日期）各一次  

**不做默认日常**：早晚各刷一次帖数、脚本挂了没人知道。

### 分阶段方案

| 阶段 | 谁做 | 放哪 | 做什么 |
|------|------|------|--------|
